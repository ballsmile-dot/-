# 삼별초, 어쩔 수 없는 선택

초등학교 5~6학년 **사회(고려·삼별초)** 단원을 위한 브라우저 학습 게임입니다.  
한 개의 HTML 파일만 있으면 **인터넷 없이** 실행할 수 있습니다.

## 실행 방법

1. `sambyeolcho-game/index.html` 파일을 **Chrome**(또는 Edge, Safari)에서 엽니다.  
   - 더블 클릭하거나, 브라우저 창에 파일을 끌어다 놓으면 됩니다.
2. **게임 시작** 버튼을 누릅니다.
3. 교실 빔프로젝터에서는 브라우저를 전체 화면(F11)으로 쓰면 글씨가 잘 보입니다.

## 조작법

| 구분 | 방법 |
|------|------|
| **이동** | 방향키 또는 `W` `A` `S` `D` |
| **발사** | `스페이스` (누르고 있으면 연사) |
| **일시정지** | `P` |
| **태블릿** | 화면 **왼쪽 절반**을 터치해 조이스틱으로 이동, 적 방향으로 **자동 발사** |
| **소리** | 오른쪽 위 **소리 끄기/켜기** |

시작 화면에서 **쉬움 / 보통** 난이도를 고를 수 있습니다.

## 게임 흐름 (약 6~7분)

1. **선택 카드** – 조정의 명령을 따를지, 남아 싸울지 등 역사적 딜레마를 고릅니다. (정답 표시 없음)
2. **1단계 강화도 탈출 (1270)** – 바다에서 쫓기는 배를 피하며 약 2분 버티기
3. **선택 카드** – 곡식 나누기
4. **2단계 진도 용장성 (1270~1271)** – 성벽을 지키며 약 2분 방어
5. **선택 카드** – 항복할지 제주로 갈지
6. **3단계 제주 항파두리성 (1271~1273)** – 여몽연합군의 공격을 최대한 오래 막기 (이기는 결말 없음)
7. **엔딩** – 1273년 함락 사실, 나의 선택 vs 실제 역사, 점수·토론 질문

플레이어 체력 대신 **사기·방패** 막대가 줄어들면 **「잠시 물러납니다」** 후 다시 도전할 수 있습니다.  
피·사망 묘사 없이, 적은 연기와 함께 물러납니다.

## 교사용 안내

- **역사 순서**는 교과서 흐름(강화도 → 진도 → 제주)을 따릅니다.  
  어떤 선택을 해도 이야기는 실제 역사대로 이어지며, 선택 직후 **「실제 역사에서는…」** 문장이 나옵니다.
- **토론**은 엔딩 화면의 질문을 활용하세요.  
  예: 「삼별초의 선택은 정말 어쩔 수 없었을까?」「백성은 어떤 마음이었을까?」
- **세력 표현**: 「여몽연합군」「고려 조정」 등 중립적 표현을 사용했습니다.
- **개인정보**: 이름 입력·서버 전송 없음. **최고 점수**만 기기 `localStorage`에 저장됩니다.
- 태블릿 수업 시 충전·전체 화면·소리 음소거(시작 화면 버튼)를 미리 안내해 주세요.
